# 节奏、结构与时间

专业动态图形和业余作品最大的区别不在效果多少，而在**时间**：动作落在哪一拍、快慢如何对比、哪里停下来。本文件给出可以直接套用的数字。

## 1. 拍点网格

即使没有音乐，也要假想一条节拍。观众会下意识感到“卡点”的舒适，以及“没卡上”的别扭。

| BPM | 1 拍 B（秒） | 1 小节 4B（秒） | 30 秒 ≈ 多少拍 | 适合 |
|---|---|---|---|---|
| 60 | 1.000 | 4.00 | 30 | 奢华、书法 |
| 72 | 0.833 | 3.33 | 36 | 悬疑片头 |
| 90 | 0.667 | 2.67 | 45 | 电影感叙事 |
| 100 | 0.600 | 2.40 | 50 | 科技 |
| 120 | 0.500 | 2.00 | 60 | 通用、理性 |
| 128 | 0.469 | 1.875 | 64 | 潮流、电子 |
| 140 | 0.429 | 1.714 | 70 | 高能 |

- 在 STORYBOARD 和时间轴里一律写 `n*B`，不要写手算的小数。
- 总时长 = 总拍数 × B。按目标时长取最近的整小节数，误差 ±1 秒可以接受。例：30 秒 @128 BPM → 64 拍 = 30.0 秒。
- 一个场景内部也按拍安排：入场在第 0 拍，强调在第 1 / 3 拍，出场在最后一拍之前。

## 2. 结构模板

六段结构是片头和宣传片最常用的叙事骨架：

| 段落 | 占比 | 作用 | 典型手法 |
|---|---|---|---|
| 钩子 Hook | 0–12% | 第一秒就抓住眼球——**不要慢慢淡入** | 黑场中一个强烈的图形动作：描线、砸字、闪白 |
| 铺陈 Setup | 12–35% | 建立母题、主题词、色彩 | 遮罩升起、网格生成、解码 |
| 推进 Build | 35–60% | 场景越来越短，节奏加快（渐快） | 一拍一词、快切、分屏 |
| 英雄 Hero | 60–75% | 全片最大的视觉事件 | 放大穿越、文字墙、巨字横移、重拍 + 闪白 + 抖动 |
| 呼吸 Breath | 75–85% | 骤然安静、留白，让观众喘口气 | 一个小字、一条线、慢速视差 |
| 收束 Resolve | 85–100% | 签名：片名 / logo / slogan / 日期，稳稳停住 | 遮罩升起 + 光扫，停留 ≥ 1.5 秒 |

## 3. 能量曲线

给每个场景标 1–5 的能量值，画成曲线检查：

```
能量 5 |                      ████
     4 |              ██  ██  ████
     3 |  ████    ██  ██  ██  ████          ██████
     2 |  ████████████████████████          ██████
     1 |  ████████████████████████  ████    ██████
        s1    s2   s3  s4  s5   s6    s7     s8
```

- 不能连续 3 场同一能量——平坦就是无聊。
- 英雄之前最好有一次“吸气”：一两拍的极简画面，或者把元素全部清空，让英雄的冲击更强。
- 呼吸场之后的收束能量回升到 3，而不是继续沉下去。

**能量与手法对照**：

| 能量 | 元素数 | 运动速度 | 典型手法 |
|---|---|---|---|
| 1 | 1–2 | 极慢 / 静止 + 镜头缓推 | 一个小字，一条线 |
| 2 | 2–4 | 慢 | 遮罩升起、光扫、视差 |
| 3 | 4–8 | 中 | 解码、描线、网格、分屏 |
| 4 | 多 | 快 | 一拍一词、律动条、形状爆发 |
| 5 | 满屏 | 爆发 | 砸字 + 闪白 + 抖动、文字墙、放大穿越 |

## 4. 缓动：用哪种、为什么

真实物体有质量：启动需要加速，停下需要减速。线性运动看起来像机器或幻灯片，这就是业余感的主要来源。

| 动作 | 缓动 | 原因 |
|---|---|---|
| 入场（出现、升起、滑入） | `expo.out` / `glide` | 快速到达、长时间安顿——眼睛立刻注意到，又有落定感 |
| 出场（消失、滑出） | `expo.in` | 慢慢启动、加速离开；不抢下一场的戏 |
| 位移、擦除、面板 | `snap` / `expo.inOut` | 两端都干脆，中段极快，像被磁铁吸过去 |
| 甩镜、瞬移 | `whip` | 几乎是切，但带有动势 |
| 弹出、贴纸、俏皮元素 | `back.out` / `punch` | 过冲后回弹，有弹性和重量（P6 常用，P1 / P5 禁用） |
| 持续运动（旋转、漂移、跑马灯、视差） | `linear` / `sine.inOut` | 不应该有起止感，像一直在那里运动 |
| 呼吸、明暗起伏 | `sine.inOut` | 柔和往复 |

**出场比入场快**：出场时长约为入场的 50–70%。观众关心的是新出现的东西。

|---|---|---|
| 逐字入场 | 0.5–0.9s | 0.02–0.05s |
| 逐词入场 | 0.6–1.0s | 0.06–0.12s |
| 逐行遮罩升起 | 0.8–1.2s | 0.10–0.15s |
| 列表、卡片、形状群 | 0.5–0.8s | 0.06–0.15s |
| 砸字（scale + blur → 1） | 0.35–0.6s | — |
| 线条描绘 | 0.6–1.4s | 0.08–0.2s |
| 色块擦除（半程） | 0.3–0.5s | 多层 0.05–0.08s |
| 圆形扩张、斜切 | 0.5–0.8s | — |
| 甩镜 | 0.3–0.4s | — |
| 闪白退去 | 0.12–0.3s | — |

stagger 总跨度（each × (n−1)）最好不超过动作本身时长的 1.5 倍，否则会像在排队。

## 6. 节奏型

把下面的节奏型组合起来，避免“每件事都在同一个速度发生”。

- **快—快—停**：两个快速动作之后，接一个停顿。最基础的节奏单元。
- **渐快（accelerando）**：推进段的场景时长 8 → 6 → 4 → 2 拍，或一拍一词时间隔 1 → ½ → ¼ 拍，制造冲向英雄的紧张感。
- **吸气—爆发**：英雄前清空画面 1–2 拍（甚至黑场），然后在下一小节第 1 拍全部爆发。
- **呼应（call & response）**：左边出现一个元素，右边在下一拍回应一个；或者大字砸下，小字在反拍跟进。
- **切分**：偶尔把一个小动作放在反拍（第 1.5、2.5 拍），打破机械感——仅限次要元素。
- **三速分层**：同一时刻，背景慢速漂移（linear）、主体快速入场（expo.out）、细节中速闪动（scramble、计数）。

## 7. 可读性与停留

- 文案完全可读的停留时间 ≥ 0.6 秒 + 每个英文词 0.25 秒（中文每字 0.15 秒）。例：“MAKE IT MOVE” 至少 1.35 秒；“让每一帧都有意义”（8 字）至少 1.8 秒。
- 一拍一词的快切蒙太奇例外：单词可以只停一拍，但整组词的意思要在停在最后一个词时成立。
- 英雄句和结尾签名停留更久：英雄句 ≥ 1 小节，签名 ≥ 1.5 秒（建议 2–3 秒）。
- 同一时刻只让观众读一处文字；小号标签和细节可以同时出现，因为它们是“纹理”，不要求阅读。
